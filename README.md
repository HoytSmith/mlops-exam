# MLOps Exam Portfolio

This repository is a portfolio of hands-on assessments completed as part of an MLOps exam designed to evaluate my ability to work across the full machine learning and MLOps lifecycle. The work demonstrates both technical depth and practical understanding of how modern ML systems are built, trained, automated, deployed, and managed in production-oriented environments.

The projects in this repository were created to test and showcase my capability in:

- machine learning model development and evaluation
- experimentation and model tuning
- MLOps workflow design and automation
- CI/CD pipelines for ML and application delivery
- cloud and infrastructure automation
- deployment readiness, reproducibility, and traceability

This repository is intended to serve as a public-facing portfolio for potential employers and collaborators. It reflects the kind of work I have done, the tools I have used, and the problems I have been able to solve in the space of Machine Learning and MLOps.

---

## Overview of the Exam

The assessments in this repository together represent a structured exam focused on the end-to-end responsibilities of an ML or MLOps engineer. The objective was not only to build models, but to understand how models move from experimentation to production in a reliable and scalable way.

The exam covered several core themes:

- building and evaluating ML models
- model optimization and hyperparameter tuning
- versioning and tracking with MLflow and Azure ML
- automation with CI/CD pipelines
- containerization and deployment workflows
- infrastructure as code for cloud services
- reproducible development environments and deployment pipelines

These assessments reflect a realistic software engineering mindset, combining data science work with operational discipline, automation, and production readiness.
